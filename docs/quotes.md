# Offline quote corpus

The six short quotations in `app/src/main/assets/quotes.json` are original aphorisms written for the Less Often project in 2026. They are attributed to **Less Often project, 2026**, not to a historical author. Each has a stable ID, 8–16 whitespace-delimited words, source metadata, and `CC0-1.0` licensing metadata. They were bundled during development; there is no runtime generation or network retrieval.

To the extent copyright or related rights exist in these original project texts, the project dedicates them to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). Full legal text: https://creativecommons.org/publicdomain/zero/1.0/legalcode.

The original source is the repository's `quotes.json` corpus. Attribution is displayed separately and is never part of the typed answer. A new attempt persists its chosen ID before displaying, excluding the last displayed ID across cancellation, package changes and process restarts. Matching uses trimmed/collapsed Unicode whitespace and locale-independent lowercase; punctuation remains significant.

The input suppresses context-menu/selection paste, keyboard paste shortcuts, accessibility paste/set-text, drag/drop, autofill and rich clipboard content. Keyboards can still emit arbitrary plain text as if typed; distinguishing every such insertion requires a custom keyboard and is outside this personal-use boundary. No unfinished input or attempt is restored.
